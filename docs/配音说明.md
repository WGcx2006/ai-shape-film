# 中文配音说明

中文配音版使用 Microsoft Edge 在线神经语音，通过 `edge-tts==7.3.1` 合成；音色为 `zh-CN-YunxiNeural`，语速 `-8%`，音高 `-2Hz`。这是合成旁白。配音稿直接取自 `src/captions.json` 的 31 条中文字幕。

每句在字幕开始后 0.15 秒进入，在字幕结束前留出至少约 0.2 秒。脚本移除句首句尾静音，不截断句子；只有句长超过窗口时才允许不超过 1.12 倍的变速，本次全部 31 句均无需变速。句间保留原片的音乐与画面留白。

旁白发声时，背景配乐降低 10 dB，淡入避让为 0.12 秒、恢复为 0.55 秒。混音经过双遍响度处理并测量实际 AAC 音轨。本次结果为 -16.03 LUFS，真峰值 -1.74 dBTP，音轨长 240 秒。

## 复现

按 README 安装基础依赖，生成 `out/score.wav` 和 `out/智能的形状_AI科普短片.mp4`，然后运行：

```powershell
python -m pip install -r requirements-voice.txt
python scripts/narrate.py
python scripts/verify.py out/智能的形状_中文配音版.mp4 --report out/verification-narrated.json
```

`--sample` 生成包含前两句的 16 秒试音，仍需要上述源文件；`--offline` 只使用现有语音缓存。缓存位于 `out/narration/`，以配音稿、音色、参数和依赖版本的散列区分，文件完整性通过 SHA-256 检查。

首次生成需要联网，并把中文字幕发送给语音服务；没有自行训练或分发语音模型。源码包含合成和混音脚本，语音缓存不随源码包分发。在线服务的可用性和输出可能改变，重新合成不保证与本次音频逐字节一致。

## 输出与检查

- `out/narration.wav`：对齐后的单声道人声轨。
- `out/narrated-score.m4a`：包含旁白与配乐的混音。
- `out/智能的形状_中文配音版.mp4`：中文配音成片。
- `out/narration-report.json`：逐句时间窗、速度、音量、散列及视频流检查。

视频流直接复制原片，不再次压缩。本次配音成片的视频流散列与原片相同，全片音视频解码通过，31 句旁白均在各自字幕时间窗内。技术检查可验证对齐、完整性和响度，不代替对语音读法与表达的人工判断。
