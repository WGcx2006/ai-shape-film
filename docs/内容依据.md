# 《智能的形状》内容依据与画面约束

核查日期：2026-10-15。成片时长 240 秒。字幕为原创中英双语表述；不引用论文原句，不涉及最新模型排名、产品能力或未经核验的创作归属。

## 叙事范围

影片依次展示机器学习的一般训练过程、向量表示、因果 Transformer 文本生成及经典 DDPM 图像生成。它们是相关但不等同的技术路线。影片没有声称所有人工智能均为大语言模型，也没有将计算能力等同于人类意识或理解。

## 可视化的准确性边界

1. **训练与泛化**：分类散点或拟合曲线是教学用合成数据。明确区分训练样本和未见测试样本。不可把训练拟合成功直接展示成泛化成功；不可将训练描述为把整个数据集原样储存。
2. **梯度下降**：如使用公式，采用 `θ ← θ − η∇θL`。上坡梯度和向下更新箭头必须方向相反。二维地形是高维参数空间的示意；不能声称每步必降、一定到全局最优或训练损失低即可靠。
3. **向量空间**：显示为二维或三维的点云是表示空间的投影或艺术示意，不是完整高维语义地图。相邻关系表达“可能有关联”，不是逻辑等价或事实证明。可在画面角落注明“向量空间示意”。
4. **因果自注意力**：若行代表查询位置、列代表键位置，屏蔽 `列 > 行` 的上三角，允许当前位置及此前位置参与。演示 `softmax(QKᵀ / √dₖ + M)V` 时，未来位置的 `M = −∞`，其余为 0。多头权重和连线为教学示意，不应冒充某个真实模型的测量结果。Transformer 还包含前馈层等结构；不要将整个模型画成只有注意力。
5. **注意力与解释**：权重可展示信息混合方式，但不自动构成模型判断的完整因果解释。此问题有实验争议，不能把任一极端当成定论。参见 [Jain 与 Wallace，2019](https://aclanthology.org/N19-1357/) 与 [Wiegreffe 与 Pinter，2019](https://aclanthology.org/D19-1002/)。
6. **词元与概率**：词元不必等于一个汉字或一个英文单词。示例概率应和为 1，并注明“示意概率”。选择过程可能使用采样或确定性解码，因此字幕使用中性的“选出一个”，不说模型永远选概率最高者。此处展示的是基础自回归生成机制，不代表所有 AI 系统的全部工作过程。
7. **扩散去噪**：本片说明经典 DDPM 的一种常用噪声预测参数化，不涵盖所有生成式图像系统。画面若由预设图形与噪声插值组成，应标注“去噪过程示意”；它展示概念，不能声称实际运行了训练过的扩散模型。生成不等于复原唯一一张原图。文字条件若出现，可仅标作“条件提示”，不要暗示 DDPM 原论文已经提出完整现代文生图产品。
8. **事实核查**：依据文献中的具体研究结果，不声称任何模型永远幻觉或永不幻觉。查验来源、测试结论、承担决策责任是影片的使用建议，不冒充论文中的实验定律。引用或检索本身也不保证正确，仍应检查来源与结论是否对应。

## 字幕与节奏

`src/captions.json` 使用全片绝对秒数，共 31 条。单条持续 5–7 秒。主标题 16–24 秒不放底部字幕；各章保留少量呼吸间隔。冷开场 2 条，主要章节各 3–4 条，结尾 2 条。英文为语义对应的简洁译文，不要求逐字翻译。

冷开场的“句子成为图像”是主题引子；结尾的“理解机制，才能用好力量”是创作主张。不得将两句扩展成模型具备人类理解或自由意志的证据。
